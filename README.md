# THE NLP QUEST BOARD

A medieval RPG-inspired academic portfolio for P. Ganesh Prakadesh (23MIC0020), documenting coursework from Natural Language Processing and Computational Linguistics at VIT Vellore.

## Run locally

Requirements: Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

To create a production build:

```bash
npm run build
npm run preview
```

## Included content

- Medieval parchment quest-board landing page with clickable notices.
- RPG journal interface with quest register, map, codex and achievements.
- Classroom questions and illustrative DFA interaction.
- Thirukkural translation comparison and evaluation rubric.
- SEMMAI project archive, eight proof checks, SQL boundary demonstration and original presentation photograph.
- Chinese Biographical Database team case study and three-star faculty recognition.
- Cohere individual case study and embedded original PDF.
- Editable personal journal saved in browser local storage.
- Responsive layout, reduced-motion support and keyboard shortcuts (Esc, /, J).

## Source files and assets

- `public/assets/semmai-presentation.png` — original classroom presentation photograph.
- `public/assets/semmai-presentation.pptx` — original SEMMAI presentation.
- `public/assets/cohere-case-study.pdf` — original Cohere submission.

The parchment, wood, map and ornamental treatments are created with original CSS and SVG artwork in the application. Google Fonts are loaded online for Cinzel, EB Garamond and IM Fell English; system serif fallbacks are provided.

## Notes on academic accuracy

- The English corpus answer remains a placeholder because the source materials do not identify the corpus discussed in class.
- The DFA visual is explicitly an illustrative automaton, not a reconstruction of the classroom example.
- Thirukkural similarity is not assigned a numeric cosine score; the interface marks TF-IDF calculation as pending.
- SEMMAI performance figures are labelled as claims reported in the presentation.
- Chinese Biographical Database applications are labelled as proposed directions, not implemented systems.
- Cohere company and revenue statements follow the supplied student submission and are not presented as independently verified current facts.

## Progress and privacy

Quest exploration/completion states and personal journal entries are stored in the current browser using local storage. No account or server is required.
